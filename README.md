# Picture Backend - 图片管理系统后端

基于 Spring Boot 的企业级图片管理平台后端服务，支持公开图库、私有空间、团队协作等多种场景，集成 AI 图像处理和实时协作功能。

## 🛠 技术栈

### 核心框架
- **Spring Boot 2.7.6** - 基础框架
- **Java 17** - 开发语言
- **MyBatis Plus 3.5.9** - ORM 框架

### 数据存储
- **MySQL** - 关系型数据库
- **Redis** - 缓存与会话存储
- **ShardingSphere 5.2.0** - 分库分表中间件

### 对象存储与云服务
- **腾讯云 COS** - 对象存储服务
- **阿里云 AI** - 智能图像处理（扩图、颜色分析等）

### 权限认证
- **Sa-Token 1.39.0** - 轻量级权限认证框架
- **Spring Session** - 分布式会话管理

### 实时通信
- **WebSocket** - 实时双向通信
- **Disruptor 3.4.2** - 高性能无锁队列

### 工具库
- **Hutool 5.8.26** - Java 工具类库
- **Jsoup 1.15.3** - HTML 解析器
- **Caffeine** - 本地缓存
- **Lombok** - 代码简化

### 文档与测试
- **Knife4j 4.4.0** - API 文档（Swagger 增强版）
- **JUnit** - 单元测试

## ✨ 核心功能

### 1. 用户管理
- 用户注册、登录、信息维护
- 角色权限控制（普通用户/管理员）
- 会话管理与持久化

### 2. 图片管理
- **多种上传方式**
  - 文件上传（支持最大 10MB）
  - URL 远程上传
  - 批量上传
  
- **图片处理**
  - 自动生成缩略图
  - 图片信息提取（尺寸、格式、色调等）
  - AI 智能扩图（Out Painting）
  - 颜色相似度搜索
  
- **图片检索**
  - 多维度筛选（分类、标签、名称）
  - 分页查询
  - 颜色搜索
  - 以图搜图（Image Search API）

### 3. 空间管理
- **三种空间类型**
  - 公开图库：所有人可见，需审核
  - 私有空间：个人专属，仅创建者访问
  - 团队空间：多人协作，角色权限控制
  
- **空间级别**
  - 普通版、专业版、旗舰版
  - 不同级别限制容量和数量
  
- **空间分析**
  - 存储空间使用统计
  - 图片数量趋势分析
  - 分类占比分析

### 4. 团队协作
- **成员管理**
  - 邀请成员加入团队空间
  - 三种角色权限：
    - 管理员（admin）：完全控制权
    - 编辑者（editor）：可上传、编辑
    - 浏览者（viewer）：仅查看
  
- **权限控制**
  - 基于 Sa-Token 的细粒度权限验证
  - AOP 切面统一鉴权
  - 操作审计日志

### 5. 实时协作
- **WebSocket 实时通信**
  - 图片协同编辑
  - 实时状态同步
  - 高性能消息队列（Disruptor）

### 6. 内容审核
- 图片上传后自动进入待审核状态
- 管理员审核机制（通过/拒绝）
- 审核记录追踪
